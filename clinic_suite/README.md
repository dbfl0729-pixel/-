# 클리닉 통합 앱 (가격표 · 단품 테이블 · 검색/계산기/장바구니 · 재고 · 관리자)

## 1) 실행
- 폴더를 그대로 Netlify에 드래그&드롭 배포 (정적 사이트)
- 또는 로컬에서 `index.html`을 실행

## 2) 데이터 저장
- 브라우저 로컬 저장(기기별)입니다.
- 좌측 하단 **데이터 내보내기/가져오기**로 백업/복구하세요.

## 3) 요구사항 반영
- 왼쪽 사이드바 내비게이션
- 가격표(프로그램/이벤트) + 단품 레이저 테이블
- 검색 / 계산기 / 장바구니
- 가격표 ↔ 재고 ↔ 관리자 페이지 (사이드바로 이동)
- VAT 문구 자동 노출(이벤트 제외)
- Program Details 넓은 박스 + Effect 강조

## 4) 관리자 편집
- 관리자 페이지에서 JSON 편집으로 가격표를 일괄 수정합니다.
- 재고 페이지의 '연결 ID'를 가격표 item의 id와 동일하게 맞추면, 가격 카드에 재고 배지가 자동 표시됩니다.
