이 파일은 '정적 HTML' 버전입니다.

사용법:
1) 압축 풀기
2) index.html 을 눌러서 바로 열기 (아이폰/아이패드/PC 모두 가능)

포함 기능:
- 왼쪽 사이드바 내비게이션
- 가격표(프로그램/이벤트)
- 이벤트 제외 VAT 문구 자동 규칙
- 단품 레이저 표(Table)
- 검색
- 장바구니(견적 복사)
- 계산기(장바구니 합계 + 할인/추가)

데이터 수정:
- index.html 안의 '데이터' 영역(programSections / singleLaserItems / inventorySeed)만 수정하면 됩니다.
