# my_site_project

## 구조
- `/index.html` : 홈페이지(링크 허브)
- `/site/*` : 일반 페이지(가격안내/소개/문의)
- `/apps/inventory/` : 재고관리 PWA (오프라인 캐시 + 홈 화면 추가)
- `/apps/consult/` : 상담/가격표 앱 (로컬 저장)

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root)

## iOS 홈 화면 추가
Safari로 `.../apps/inventory/index.html` 접속 → 공유 → 홈 화면에 추가
