일일 재고 마감 (B방식)

퇴근 시 실제 재고(마감)를 입력합니다. “당일 사용(직원 입력)”은 직접 작성하고, “자동 사용량”은 참고값입니다(저장 차단 없음).
품목명 카테고리 전일 실재고 퇴근 실재고(마감) 당일 사용(직원 입력) 자동 사용량(참고) 오차 당일 소모비용

저장된 일일 기록

날짜 품목 마감 재고 직원 사용 자동 사용 오차 소모 비용 메모 작업
자동 사용량(참고) = 전일 실재고 + (입고 참고[선택]) - 퇴근 실재고. 오차 = 자동 사용 - 직원 사용.

입고 기록

날짜 품목 입고 수량 입고 단가 입고 금액 메모 작업
입고 단가 기록은 이후 수정되지 않는 스냅샷 값으로 사용(해당 기록 수정은 가능하지만, 과거 소모 기록의 단가 스냅샷은 잠금).

출고(사용) 기록

날짜 품목 사용 수량 단가(스냅샷) 사용 금액 메모 작업
출고 기록은 재고(실재고) 방식은 건드리지 않고, 비용/소진예측/리포트 정확도를 올리기 위한 보조 기록입니다.
